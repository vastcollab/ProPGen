# Symbolic derivations

Mathematica notebooks containing the symbolic derivations behind the analytic
results, for the two-genotype case in both continuous and discrete time.

These are derivations, not figure code: no figure in the paper is produced
here. The Python implementation of the resulting equilibrium is
`propgen.equilibrium` (`src/propgen/theory.py`).

Opening them requires Mathematica 13.1 or later.
